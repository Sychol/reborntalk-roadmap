# 리본톡 통합 로드맵 홈페이지

리본톡(re;borntalk)의 개발·실증·기관 공급 로드맵을 한 화면에서 이해할 수 있도록 구성한 정적 React 홈페이지입니다.

## 구현 범위

- Hero / 프로젝트 요약
- 통합 로드맵 overview
- 단계별 로드맵 카드
- 개발 관점 vs 상품화·기관 공급 관점 과제 매트릭스
- 기관 공급 준비 체크리스트
- 내부 근거자료 및 표현 가드레일
- 다음 30일 작업 callout

로드맵 문구와 상태값은 `src/data/roadmap.ts`에서 관리합니다.

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 출력하는 로컬 주소를 브라우저에서 열면 됩니다.

## 검증 방법

```bash
npm test
npm run build
```

`npm test`는 필수 섹션, 필수 표현, 금지 표현, 로드맵 단계 수, 체크리스트 그룹 수, 반응형 CSS 유무를 확인합니다.

## 표현 원칙

리본톡은 AI 기반 정신건강 관리 서비스로 설명하며, 자가점검, 위험 신호 확인, 초기개입, 전문가 연계, 기관 단위 예방관리의 맥락을 유지합니다. 전문가의 평가나 응급의료를 대체하지 않는다는 면책 문구를 화면에 포함했습니다.
